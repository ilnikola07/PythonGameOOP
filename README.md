# PythonGameOOP — Консольная стратегия на Python

Пошаговая консольная стратегия, реализованная на языке Python с применением парадигмы объектно-ориентированного программирования (ООП). Игра демонстрирует практическое использование классов, интерфейсов, наследования, перегрузки операторов и полиморфизма.



## Краткое описание

Игрок управляет собственной военной базой: накапливает ресурсы, нанимает отряды различных типов и координирует их действия на тактической карте. Юнитов можно перемещать, атаковать ими вражеские цели, взаимодействовать с элементами ландшафта и собирать нейтральные объекты.

### Основные возможности
* **Управление базой:** Производство юнитов с контролем лимитов населения и доступного золота.
* **Управление юнитами:** Перемещение по игровому полю, проверка радиуса атаки и ведение боя.
* **Система боя:** Разделение на ближний и дальний бой, механика урона от скрытых ловушек, лечение с помощью аптечек.
* **Случайная генерация:** Карта размером 15×15 клеток со случайно распределенным ландшафтом и интерактивными объектами.
* **Разнообразие войск:** 6 уникальных типов юнитов (пехота, лучники, конница), обладающих индивидуальными характеристиками.



## Системные требования и зависимости

* **Версия Python:** 3.14 или выше.
* **Библиотеки:** Используется только стандартная библиотека Python (без внешних зависимостей).
* **Модули:** `random` (применяется для генерации карты).
* **Интерфейс:** Терминал с обязательной поддержкой ANSI-цветов (например, Windows Terminal, Git Bash, macOS Terminal или PowerShell).

## Руководство пользователя

После старта приложения на экране отобразится сгенерированная карта и главное меню:

```text
=== ГЛАВНОЕ МЕНЮ ===
1 - Управление базой
2 - Управление юнитом
3 - Состояние базы
4 - Выход
```

### 1. Управление базой
Позволяет нанимать новых бойцов. Стоимость создания любого юнита составляет **10 золота**.

| Иконка | Тип юнита | HP | Атака | Дальность | Описание |
| :---: | :--- | :---: | :---: | :---: | :--- |
| **W** | Воин | 50 | 10 | 1 | Ближний бой, имеет устойчивость к ловушкам |
| **G** | Страж | 45 | 12 | 1 | Ближний бой |
| **A** | Стрелок | 30 | 15 | 2 | Дальний бой, уязвим к ловушкам |
| **S** | Снайпер | 35 | 18 | 3 | Дальний бой, уязвим к ловушкам |
| **R** | Всадник | 60 | 8 | 1 | Ближний бой |
| **L** | Улан | 40 | 14 | 1 | Ближний бой |

### 2. Управление юнитом
Выберите конкретного юнита из списка доступных, чтобы отдать ему приказ:
* `1` — **Перемещение:** смещение на одну клетку (вверх / вниз / влево / вправо).
* `2` — **Атака:** выбор и поражение цели, находящейся в радиусе действия оружия.
* `3` — **Состояние:** просмотр текущего запаса HP, силы атаки, дальности и координат позиции.
* `4` — **Назад:** возврат к общему списку отрядов.

### 3. Состояние базы
Выводит на экран текущие стратегические показатели:
* Баланс золота.
* Текущий состав войск (группировка по типам).
* Лимиты на создание юнитов.

### Легенда карты

* **Юниты:** `W` — Воин, `G` — Страж, `A` — Стрелок, `S` — Снайпер, `R` — Всадник, `L` — Улан.
* **База:** `B` — Цитадель.
* **Объекты:** `+` — Аптечка, `$` — Золото, `x` — Ловушка, `T` — Дерево.
* **Ландшафт:** `.` — Трава, `~` — Вода (непроходимая), `^` — Горы (непроходимые).

## Список выполненных задач

### Задача 1: Основные классы
* Разработан класс игрового поля (`GameField`) с сеткой 15×15 и алгоритмом генерации.
* Реализован контроль лимитов на максимальное количество объектов на карте.
* Добавлена возможность динамического добавления и удаления игровых объектов.
* Реализована функция глубокого копирования поля вместе со всеми объектами.
* Спроектирована архитектура юнитов на базе общего интерфейса `EntityInterface`.
* Создано 6 классов юнитов (3 архетипа по 2 вида в каждом).
* Настроены базовые характеристики: здоровье, атака, дальность.
* Запрограммировано перемещение юнитов по двумерной сетке.

### Задача 2: Интерфейсы классов, взаимодействие, перегрузка операций
* Создан класс базы (`Base`), отвечающий за производство войск, учет ресурсов и лимитов.
* Реализованы 3 типа ландшафта (`Grass`, `Water`, `Mountain`) с общим интерфейсом.
* Настроено влияние ландшафта на логику перемещения (блокировка движения через воду и горы).
* Добавлены 4 типа интерактивных объектов (`HealthPotion`, `GoldCoin`, `Trap`, `Tree`).
* Перегружен оператор `+` для обработки подбора предметов и активации объектов юнитами.
* Перегружен оператор `-` для проведения вычислений во время атаки между юнитами.

### Задача 3: Взаимодействие пользователя с игрой
* Реализован удобный текстовый интерфейс для покупки юнитов в меню базы.
* Написано консольное подменю для пошагового управления действиями выбранного персонажа.
* Интегрировано информативное отображение текущего статуса армии и базы.
* Сформирован цветной вывод карты в терминал с отображением координатной сетки для удобства навигации.
